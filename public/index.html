Icons are stored on your SharePoint site, so they show here as dashed boxes. They appear once the code is pasted into a page on SharePoint. The Spectrum Sans Light font also only applies there.

HTML to paste

  1. On your SharePoint page, add a Text or Embed web part, or edit an existing content web part.
  2. Switch it to Source (the </> button), select everything, and paste.
  3. Save the web part, then republish the page.
